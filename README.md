# TaskFlow — Modern To-Do & Productivity Web App

A modern, fast, responsive To-Do List application crafted with **HTML5**, **Tailwind CSS**, custom **CSS3**, and **Vanilla JavaScript**.

---

## ✨ Features

- **🎨 Modern Glassmorphic UI**: Clean, responsive layout with smooth transitions and subtle backdrop blurs.
- **🌙 Dark / Light Mode**: Seamless dark and light themes with preference persistence.
- **📊 Real-time Productivity Metrics**:
  - Live task completion percentage and animated progress bar.
  - Counters for Total, Completed, and Pending tasks.
- **🏷️ Categorization & Priorities**:
  - Assign priorities: `High`, `Medium`, `Low` with color badges.
  - Organize into categories: `Work`, `Personal`, `Study`, `Health`, `Finance`, `General`.
- **📅 Due Dates & Overdue Alerts**:
  - Visual badges for "Due Today" and "Overdue" tasks.
- **🔍 Fast Search & Filtering**:
  - Live instant search across task names and categories.
  - Filter by status: `All`, `Pending`, `Completed`, `Due Today`.
  - Filter by specific categories.
- **🔃 Multi-Criteria Sorting**:
  - Sort by Newest, Oldest, Due Date, Priority, or Alphabetically.
- **✏️ In-Place Task Editing**: Edit task title, priority, category, or due date in a modal.
- **↩️ Undo Task Deletion**: Toast alert with an "Undo" action when a task is removed.
- **🎉 Celebration Confetti**: Canvas confetti animation upon completing all tasks!
- **🔊 Subtle Audio Synthesizer**: Native Web Audio API chime on task completion (can be toggled on/off).
- **💾 LocalStorage & Data Management**:
  - Automatically saves all tasks and settings locally.
  - Export tasks to JSON file.
  - Import tasks from JSON file.
  - "Clear Completed" & "Reset All" options.
